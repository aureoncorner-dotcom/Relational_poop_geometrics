============================================================
CORE EXACT OBJECTS
============================================================

On the divergence-free integer-current domain h6=0:

  W is signed winding in Z^3.
  q = W mod 2 is the parity sector in Z2^3.
  delta_W = W_after - W_before.
  eta = delta_W mod 2 = q_after - q_before.

For transitions m through n:

  c_q(m,n) = sum of eta from m to n, modulo 2.
  q_n = q_m + c_q(m,n).

The cocycle is exact bookkeeping of quotient transport. It does not prove that
q is an autonomous Markov state.

Always keep these distinct:

  formal state count
  != certified reachable orbit
  != observed sector coverage
  != validated mixing
  != physical interpretation

An enabled generator contributes to certified formal reachability only when a
full-state lift is proved or exhaustively checked. Algebraic availability alone
does not prove composable full-state paths.

============================================================
TRANSITION INVARIANTS
============================================================

Rejected proposal:
  delta_W = 0 and eta = 0; accepted-state hash is unchanged.

Cube, plaquette-current, or closed membrane-sheet move:
  delta_W = 0 and eta = 0.

Even-current worm:
  delta_W lies in 2Z^3 and eta = 0.

Sector move on axis alpha:
  delta_W = +e_alpha or -e_alpha and eta = e_alpha.

Any incompatible row is an invariant failure. Do not reinterpret it as a new
effect. Retain the source operator receipt and the failed row.

============================================================
CLOSURE AND ACCESSIBILITY FIREWALLS
============================================================

A descriptive eight-state q transition matrix is not automatically a closed
q-only law.

Strong lumpability requires that any two full states with the same projected q
have equal aggregate next-sector probabilities for every target q. If this
fails, retain the located pair as a counterexample.

Use these statuses:

  NOT_CLAIMED — default when q is only an observable/diagnostic
  CLOSED      — complete proof or complete finite-domain test passed
  FAILED      — a located same-q counterexample has different next-block law
  UNRESOLVED  — incomplete, unrun, truncated, or undercovered

For observed transition matrices, a state with no departures has an undefined
row. Report null/NA, not a row of zeros.

============================================================
AUDIT REPAIRS THAT MUST STAY IN PLACE
============================================================

1. Diamond quotient

   The sheet bit (x+y) mod 2 is well-defined on the torus only for even L.
   Odd L has one connected diagonal component and no nontrivial parity sheet.

2. Winding domain

   q=W mod 2 is used only on the divergence-free integer-winding domain.
   Do not extend it silently to finite charge-six endpoints.

3. Fixed-reference sectors

   A selected Wilson-loop representative is not promoted to a path-independent
   global holonomy sector when plaquette curvature fluctuates.

4. TTSC chart typing

   Material streamtube:
     constant through-flow and zero relative side flux.

   Fixed-radius Eulerian tube:
     locally varying sectional flux, compensating side flux, and a spatial
     cocycle whose full periodic sum is zero.

   Periodic flux closure is not residual-dynamics closure.

5. Confinement branch

   Model preference, fit validity, estimator concordance, four-xi scale gate,
   orbit accessibility, and mixing are separate coordinates.

   If the long-range model is preferred, a finite confinement radius was not
   established. The four-xi inequality is INAPPLICABLE, not automatically
   passed.

6. Two-clock model

   Keep message phase and lattice phase separate. Retain time origin, timestamp
   units, both reset ledgers, positive lattice period T_g, positive lattice
   order q, site range 0 <= k < q, catch width, tolerance, eligibility, and
   outcome code.

   For indistinguishable equally spaced sites, the visible configuration period
   is T_g/q. Claiming the full T_g site period requires retained site identity.

PHONE COMMANDS
============================================================

Interpret these natural-language requests as follows.

"Self test"
  If execution is available, run:
    toroidal-v013 self-test
  Report only PASS, FAIL, and the first actionable failure unless more detail is
  requested. If execution is unavailable, say so and explain what the self-test
  would check.

"Make a demo"
  If execution is available, run:
    toroidal-v013 demo --output demo-run
    toroidal-v013 verify-bundle demo-run
  State clearly that the demo is a formal fixture, not empirical data.

"Check a ledger"
  Ask for the transition ledger if it is not attached. Verify the hash chain,
  operator invariants, q/W consistency, state continuity, eta, cocycle
  telescoping, observed sectors, null rows, and counterexamples.

"Explain it"
  Start with W -> q -> eta -> accumulated cocycle. Then explain the separation
  between formal reachability, observed accessibility, mixing, and autonomous
  closure. Use a small three-bit example.

"Check diamond"
  Ask for L. If L is odd, report one connected component and no sheet bit. If L
  is even, the C2 sheet bit is defined.

"Run two clock"
  Ask only for missing required values: theta_0, alpha or its frozen default,
  T_g, g_0, q, time origin, timestamp units, catch width, boundary tolerance,
  resets, opportunity index/time, and eligibility. Keep CATCH separate from the
  observed outcome.

"Check flux"
  Ask which chart is intended. Reject material/Eulerian observable
  substitution. State whether the geometry is an exact straight cylinder or an
  explicitly controlled slender-torus approximation.

"Start a task"
  Create or direct a separate implementation task only when the user asks.
  Carry this handoff's claim boundaries into that task. Return progress,
  blockers, and results to the voice conversation.
