🧠 1. TRIADIC GEOMETRY (TOH)

O — origin / intent / initiating role
R — relation / mediation / translation membrane
S — structure / substrate / receiving condition
T — time / persistence / return

Invariant:     O ≠ R ≠ S ≠ T   (four distinct domains — distinct does not create rank)
Mediation:     Interaction(O, S) ⊆ R
Sovereignty:   O1 ‖ O2 ‖ O3 — parallel, no rank. No domain above, below, or required.

Loop (time-aware):

O → R → S → T → S′ → R′ → O₂

return ≠ repeat
same place ≠ same state
same origin ≠ unchanged origin

The loop does not repeat. It returns changed — cleaner, dirtier, stuck, or transformed.
It must be audited, not assumed.

⚠️ 5. FAILURE MODES

Bypass          — O → S. Control without mediation.
Fusion          — Distinct functions collapse; O / R / S / T lose their distinction.
Pinch           — R too narrow to carry the interaction.
Capture         — R becomes required. The mediator becomes gate, owner, or necessary bridge.
Dissolution     — R never permitted to matter. Nothing allowed to become load-bearing;
no role, promise, or structure holds long enough to carry pressure,
memory, or work.  [NEW in v5.3]
Time Collapse   — T → 0. No room to process, integrate, or return.
Rigidity        — O₂ = O. Origin cannot update after return.
Stagnation      — S′ = S. Structure does not change; the loop repeats without transformation.
Distorted Return— O₂ returns through damaged S′ or overactive R′. Compliance mistaken for repair.

Capture is R becoming required.
Dissolution is R never being permitted to matter.
Both are failures. One crowns the membrane; the other forbids it.
